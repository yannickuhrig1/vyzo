## Vyzo 1.13.0 bêta 2 : la maison pilotée depuis l'ordinateur

**Version d'essai.** Elle n'est pas proposée automatiquement aux autres : installe-la à la main depuis les fichiers ci-dessous, ou laisse l'appli te la proposer si tu as activé les mises à jour bêta. La 1.12.0 reste la version stable.

Cette version ajoute trois choses que le site du compte peut piloter :

- **Lancer sur la TV** : depuis « Reprendre », l'historique ou une liste sur le site, choisis un appareil. Vyzo y ouvre le film, l'épisode ou la chaîne, et reprend où tu en étais. Le code parental est demandé si le titre est verrouillé. Vyzo doit être ouvert sur l'appareil.
- **État de tes abonnements** : après chaque vérification chez le fournisseur, Vyzo envoie au compte, chiffrés, la date de fin, le nombre de connexions et l'état de l'abonnement. Le site te prévient quand la fin approche.
- **Contrôle parental pour toute la maison** : depuis le site, un code parental commun à tous les appareils, la détection des catégories pour adultes, le code pour quitter un profil enfant, et le verrouillage de n'importe quelle catégorie. Tant que tu ne l'actives pas sur le site, chaque appareil garde son propre code.

Le site du compte change aussi d'allure : accueil avec l'essentiel, recherche (Ctrl K), trois thèmes au choix, annulation d'une suppression, et une page Sécurité pour changer de mot de passe ou déconnecter les autres appareils.
