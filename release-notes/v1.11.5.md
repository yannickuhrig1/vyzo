## Vyzo 1.11.5

Les fiches de films et de séries s'enrichissent, avec une clé TMDB.

- **Notes** : IMDb, Rotten Tomatoes et Metacritic sur les fiches, avec une clé OMDb personnelle à saisir dans les réglages.
- **Limite d'âge** : la classification française s'affiche sur les fiches.
- **Épisodes** : résumés et images complétés quand le fournisseur n'en donne pas.
- **Titres similaires** : sur chaque fiche, seulement ce qui est disponible dans ton abonnement.
- **Tendances** : deux nouvelles rangées à activer dans la personnalisation de l'accueil.
- **Compte Vyzo** : les clés TMDB, OMDb, OpenSubtitles et le jeton GitHub suivent ton compte, chiffrés, et un appareil qui ne les a pas ne peut plus les effacer.
- **Moins de requêtes** : les réponses sont gardées 30 jours sur l'appareil.
